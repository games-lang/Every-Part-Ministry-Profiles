---
name: Profile plan limits
description: How church subscription limits count profiles and behave after plan changes.
---

During early access, existing and ordinary new churches can create and view unlimited completed adult, Discover, Explore, and Develop Ministry Profiles, regardless of their stored billing plan. The owner approved an exception only for explicitly designated test churches to exercise planned profile-view limits during Stripe test-mode billing. Planned capacities are Starter 5, Growing 50, Complete 100, Network 250, and Unlimited with no cap. AI credit limits are separate and still apply.

**Why:** The user requested unlimited profiles during early access and explicitly chose to preserve existing churches' access while testing new billing limits. Applying Starter limits broadly before live billing is approved could hide existing admin results.

**How to apply:** Never block participant profile submissions for capacity. Keep normal early-access churches unlimited; do not infer test status from a slug or plan. Only an explicitly designated test church may see plan-based admin visibility gates in test mode. A broader rollout requires separate owner approval, and downgrades must not delete saved profiles.

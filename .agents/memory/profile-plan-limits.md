---
name: Profile plan limits
description: How church subscription limits count profiles and behave after plan changes.
---

Profile limits count every completed Ministry Profile in a church, including adult, Discover, Explore, and Develop profiles. Starter allows 5, Growing 50, Complete 100, and Network 250.

**Why:** A profile is a durable ministry record regardless of pathway, so all completed profiles consume the same church-level capacity.

**How to apply:** Enforce capacity transactionally at every profile-creation boundary. Never delete or hide existing profiles after a downgrade; if usage exceeds the new limit, preserve history and block only new submissions until capacity is available.

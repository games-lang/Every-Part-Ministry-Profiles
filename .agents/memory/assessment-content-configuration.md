---
name: Assessment content configuration
description: Compatibility rules for church-specific assessment sections and saved ministry profiles.
---

Church assessment-content choices affect new assessments only. Every submitted profile keeps the server-resolved configuration snapshot that governed its questions, and historical profile pages render from that snapshot. Active drafts may receive narrowly targeted presentation-only corrections when frozen wording is confusing, provided answer values and scoring semantics remain unchanged. Profiles created before snapshots existed use the all-enabled legacy behavior. Name and email remain required for adult profiles, while churches may independently show or hide optional About You fields. Generic passion and ministry-interest options are protected defaults; pastors may append church-specific options but cannot remove the generic set.

**Why:** Pastors may change future assessment content without erasing, reinterpreting, or unexpectedly hiding information members already submitted. A participant should not remain trapped with known-confusing labels merely because their unfinished draft predates a wording correction.

**How to apply:** Resolve configuration on the server, default legacy About You field choices to enabled, union protected generic options with validated church additions, never trust a client-provided snapshot, omit disabled inputs from new submissions, and use the stored snapshot whenever displaying an existing profile. Limit active-draft overrides to identified presentation defects; never remap numeric answers, constructs, or completed-profile history.

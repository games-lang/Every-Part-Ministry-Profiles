---
name: Profile pathway themes
description: Visual identity rules for keeping the four Ministry Profile pathways distinct but recognizably Every Part.
---

Use a shared scoped theme system across each pathway’s assessment, result, and journey views: adult is navy/teal, Discover is green, Explore is gold/amber, and Develop is indigo/blue. Keep typography, spacing, cards, and the original Every Part logo consistent.

**Why:** Pathway colors help members and leaders recognize age-specific experiences without fragmenting the product into unrelated brands. Color must remain an accent rather than the sole pathway identifier.

**How to apply:** New pathway-facing screens should inherit the matching theme class and retain visible text labels or icons for accessibility. Church branding can still govern adult assessment controls while the adult pathway background remains recognizable.

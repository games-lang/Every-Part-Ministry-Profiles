---
name: Spiritual gift configuration
description: Compatibility rule for church-specific spiritual-gift selections.
---

A church's enabled spiritual-gift configuration applies to new assessments only. Historical profiles must continue to display every gift and response stored at submission time.

**Why:** Administrators may refine the assessment later, but previous member reflections remain valid pastoral conversation records and must not change retroactively.

**How to apply:** Derive public assessment questions from the church's current configuration, while deriving pastor detail and print output exclusively from each submitted profile's stored data. Treat an unsaved configuration as all supported gifts.
